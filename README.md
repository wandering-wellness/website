# Wandering Wellness

Website for Wandering Wellness — online health coaching, nutrition coaching, and personal training with Kelsey Conway.

**Live site:** [wanderingwellness.fit](https://wanderingwellness.fit)

## Files

- `index.html` — homepage (About, Services, Contact)
- `links.html` — resources page (email list signup, app link, discount codes) — linked from the homepage nav as "Resources"
- `CNAME` — points the custom domain (wanderingwellness.fit) to this GitHub Pages site

## Updating the site

Edit `index.html` or `links.html` directly, then commit and push to this repo. GitHub Pages rebuilds automatically within a minute or two of a push.

Both HTML files are self-contained (styles and images are inlined), so no other assets or build steps are needed.
